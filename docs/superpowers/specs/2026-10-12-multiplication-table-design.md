# 초등학교 2학년을 위한 구구단 연습 게임 설계서 (Design Specification)

## 1. 개요 (Overview)
- **목적**: 초등학교 2학년(만 7~8세) 학생들의 구구단 학습을 돕기 위한 밝고 친근한 반응형 웹 기반 구구단 퀴즈 게임.
- **핵심 요구사항**:
  - 2단부터 9단 중 랜덤 1문제 출제 (곱해지는 수 2~9, 곱하는 수 1~9).
  - 답 입력란과 '확인' 버튼 제공.
  - 학생 친화적 채점 피드백:
    - 정답 시: 화면에 아주 크게 "🎉 정답! 참 잘했어요!" 표시 및 축하 효과.
    - 오답 시: "아쉬워요! 정답은 ___이에요. 다시 힘내봐요! 💪" 따뜻한 안내.
  - 피드백 확인 후 '다음 문제' 버튼(또는 Enter 키)을 통해 다음 문제로 진행.
  - 별(⭐) 칭찬 스티커 및 연속 정답(🔥) 점수판 제공.
  - PC 키보드 입력(Enter 포함) 및 태블릿/모바일 터치용 온스크린 숫자 키패드 지원.

## 2. 기술 스택 및 아키텍처 (Tech Stack & Architecture)
- **프레임워크/런타임**: React 18/19 + Vite + TypeScript
- **스타일링**: Tailwind CSS
  - 둥글둥글한 카드(rounded-3xl), 부드러운 그림자(shadow-lg), 시인성 높은 큰 글씨(text-3xl ~ text-6xl), 초등학생 취향의 밝고 따뜻한 컬러 팔레트(스카이블루, 옐로우, 핑크, 민트)
- **아이콘**: Lucide React (Sparkles, Star, Trophy, Volume2, VolumeX, Delete, Check, ArrowRight 등)
- **사운드**: Web Audio API 기반 순수 코드 신디사이저 (외부 오디오 파일 로딩 지연 없음, 도-미-솔-도 정답음 / 부드러운 오답 격려음 / 경쾌한 클릭음 생성)
- **파티클 효과**: Canvas Confetti (정답 시 폭죽 효과)

## 3. UI/UX 구성 및 레이아웃 (Component & Layout)
- **Header**:
  - 타이틀: "신나는 구구단 탐험대 🚀"
  - 스코어보드: 누적 정답 수, 연속 정답(Streak), 모은 별(⭐) 개수
  - 컨트롤: 소리 켜기/끄기(Mute) 토글 버튼
- **QuizCard (문제 영역)**:
  - 칠판/노트 스타일의 대형 카드
  - 수식 표기: `[ A ] × [ B ] = [   ]` 형태
  - 정답 입력창: 큰 글씨, 가운데 정렬, 자동 포커스
- **Keypad (터치 키패드 영역)**:
  - 1부터 9까지의 숫자 버튼, 0, ⌫ (한 글자 지우기), 확인 버튼
  - 버튼마다 귀여운 파스텔톤 컬러 및 통통 튀는 클릭 애니메이션
- **FeedbackSection (피드백 모달/오버레이)**:
  - **정답 상태**:
    - 대형 텍스트: "🎉 정답!"
    - 서브 텍스트: "참 잘했어요! 별 +1개 획득 ⭐"
    - Confetti 폭죽 애니메이션 & 딩동댕 멜로디
    - '다음 문제 풀기 ➡️' 버튼 (Enter로 즉시 넘어가기 가능)
  - **오답 상태**:
    - 대형 텍스트: "아쉬워요!"
    - 서브 텍스트: "정답은 **[num1 × num2]**이에요. 다음엔 꼭 맞힐 수 있어요! 💪"
    - 격려 사운드
    - '다음 문제 도전 ➡️' 버튼

## 4. 데이터 및 로직 흐름 (Data & State Flow)
1. **문제 생성 (`generateQuestion`)**:
   - `num1`: 2 ~ 9 사이의 정수 (랜덤)
   - `num2`: 1 ~ 9 사이의 정수 (랜덤)
   - `answer`: `num1 * num2`
   - 이전 문제와 완전히 동일한 문제는 연속으로 나오지 않도록 방지
2. **입력 처리**:
   - `userAnswer` 문자열 상태 관리 (최대 2자리 숫자)
   - 키패드 누름 또는 물리 키보드 입력 시 동기화
3. **채점 (`checkAnswer`)**:
   - 빈 값 입력 시: "숫자를 입력해줘!" 귀여운 흔들림(shake) 애니메이션
   - 일치 시:
     - `status = 'correct'`
     - `score += 1`, `streak += 1`, `stars += 1`
     - 정답 사운드 재생, confetti 발사
   - 불일치 시:
     - `status = 'wrong'`
     - `streak = 0`
     - 오답 사운드 재생
4. **다음 문제 (`nextQuestion`)**:
   - `userAnswer = ''`
   - `status = 'answering'`
   - 새 문제 생성 및 입력창 자동 포커스

## 5. 예외 및 엣지 케이스 처리 (Error Handling & Edge Cases)
- 숫자가 아닌 문자 입력 차단 (정규식 `^\d*$` 제한)
- 3자리 이상의 불필요한 긴 입력 차단 (구구단 곱셈 최대 결과는 81이므로 2자리 제한)
- 오디오 컨텍스트 자동 재생 정책: 사용자의 첫 인터랙션(버튼 클릭/입력) 시점에 AudioContext resume
- 화면 크기 반응형 대응: 스마트폰(작은 화면 세로 모드), 태블릿, PC 화면 모두 비율 유지

## 6. 검증 계획 (Verification Plan)
- TypeScript 컴파일 및 Vite 프로덕션 빌드 무결성 확인 (`npm run build`)
- 브라우저 자동화 도구(Playwright) 또는 로컬 브라우저 구동 테스트:
  - 1) 2단~9단 랜덤 문제 출제 확인
  - 2) 온스크린 키패드 클릭 및 답 입력 확인
  - 3) 정답 입력 후 '확인' 클릭 시 "정답" 및 축하 메시지 노출 확인
  - 4) 오답 입력 후 '확인' 클릭 시 "아쉬워요! 정답은 ___이에요." 문구 노출 확인
  - 5) '다음 문제' 버튼 클릭 시 새 문제로 갱신 확인
